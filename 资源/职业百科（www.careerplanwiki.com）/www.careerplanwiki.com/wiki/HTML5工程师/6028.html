任务职责

1. 负责基于 HTML 5 及 JS 等前端技术的 Web/App 前端功能开发、调试和维护，HTML/JavaScript/CSS 代码的编写，支持视觉设计以及 Web 开发的相关工作；
2. 实现项目 Web 前端(PC、H5)界面效果、交互和功能；
3. 对已有产品中的代码持续更新迭代优化和重；
4. 完成前端核心业务代码及 JS 组件的封装；
5. 配合研发团队一起研讨技术实现方案，进行应用及系统整合。

知识背景

计算机或相关专业本科及以上学历

常用工具

1. Initializr 是制作 HTML5 网站顶好的入门辅助开发工具，你可以使用提供的特色模板迅速生成网站，也可以自定义，Initializr 会为你生成代码简洁的可定制的网页模板。
2. HTML5 visual cheat sheet 是一个非常酷的速查手册，每个 Web 开发人员的必备神器，可以帮助大家高速查找一个标签或者属性。
3. Cross browser HTML5 forms是HTML5 中的日历，取色板，滑块部件等都是非常棒工具，但是有些浏览器不支持。Cross browser HTML5 forms 还可以帮助你构建完美的 HTML5 表单兼容方案。
4. HTML5demos会告诉你每一个 HTML5 特性在哪些浏览器中支持，比如说你的浏览器是否支持 HTML5 Canvas Safari是否可以运行简单的 HTML5 聊天客户端等问题。
5. Switch To HTML5 是一个基础而实用的模板生成工具。
6. HTML5 Tracker 可以跟踪 HTML5 全新修订信息。使用 HTML5 Tracker 可以了解 HTML5 的全新动向。
7. HTML5 Test 会为你当前使用的浏览器生成一份对 video、audio、canvas 等等特性的支持情况的完整报告。
8. LimeJS是一个 HTML5 游戏开发框架，用于高速构建运行于触屏设备和桌面浏览器的游戏。非常棒的 HTML5 开发工具，一定要用用试试。
9. HTML5 Reset 是一组文件，包括 HTML、CSS 等，用于在开始新项目的时候帮助你节省时间，提供 HTML5 的空白 WordPress 模板。

职业技能

具有独立完成前端开发工作的能力;
熟悉 PC 端及移动端的前端开发、多浏览器兼容及移动端机型适配方式;
熟练掌握 Web 系统开发技术，精通 JavaScript、jquery、CSS3、HTML5、Ajax，能快速定位 解决浏览器兼容性问题;
熟练使用 JS 及主流的 JavaScript 框架，如 Dojo、Bootstrap、EasyUI 等前端框架。
